# Web-based Construction Management System

**SLIIT SE2030 – Software Engineering | Year 2 Semester 1 - 2026**  
**Group**: `MLB-B6G2-02`

---

## 🏗️ Project Overview
The Web-based Construction Management System is an enterprise-grade full-stack web application designed to streamline construction project planning, workforce task allocation, real-time site progress tracking, material inventory control, supplier procurement workflows, and financial cost accounting.

---

## 🛠️ Technology Stack
* **Backend**: Java 17+ / Spring Boot 3 (`Spring Web`, `Spring Data JPA`, `Bean Validation`)
* **Database**: Microsoft SQL Server (SSMS) with `mssql-jdbc` driver
* **Frontend**: Modern HTML5, CSS3, JavaScript, Bootstrap 5 (Unified 3-Page layout)
* **Architecture**: 3-Tier Layered Package-by-Feature (SOLID Principles compliant)
